## Construcción
El proyecto incluye `.github/workflows/build-apk.yml`. Al subirlo a un repositorio GitHub y ejecutar la acción "Build APK", genera `app-debug.apk`.

La app guarda cambios en el almacenamiento interno del WebView de Android, no en Chrome.
